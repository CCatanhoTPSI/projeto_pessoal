# North "Capital"

Projeto de um site estático em português sobre corretoras, plataformas e
instrumentos financeiros.

## Tecnologias

- HTML5
- CSS3
- Imagens PNG
- Sem dependências externas

## Estrutura

- `index.html` — página inicial
- `styles.css` — estilos globais
- `Img/` — recursos visuais
- `conteudos/` — artigos do projeto, a criar na próxima fase

## Estado

A página inicial está criada e com a navegação estrutural definida. Os
artigos individuais ainda estão em desenvolvimento.

## Como abrir

Abrir o ficheiro `index.html` num browser moderno. O projeto não necessita de
ser compilado nem de instalar dependências.
